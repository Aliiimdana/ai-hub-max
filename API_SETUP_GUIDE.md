# API Setup Guide (Official Endpoints Only)

1. **Google Gemini (Free Tier available)**: https://aistudio.google.com/app/apikey
2. **Groq (Free Plan available)**: https://console.groq.com/keys
3. **OpenRouter (`openrouter/free` available)**: https://openrouter.ai/keys
4. **OpenAI (Paid)**: https://platform.openai.com/api-keys
5. **DeepSeek (Paid)**: https://platform.deepseek.com/api_keys

All keys are encrypted locally using **Android Keystore (AES/GCM/NoPadding)** and are never logged.
